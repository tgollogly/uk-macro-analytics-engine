# Sample outputs (copy for portfolio / CV)

Add **non-sensitive** snapshots here (PNG screenshots, anonymised one-pagers) if you want them in GitHub. Keep files **small** (under 500 KB each).

Suggested free assets:

- `dashboard.png` — screenshot of `data/exports/report.html` opened in your browser after `python -m src.report_builder`.
- `powerbi.png` — optional screenshot from Power BI Desktop (see `docs/POWERBI_DESKTOP.md`).

These files are **optional**; the pipeline works without them.
