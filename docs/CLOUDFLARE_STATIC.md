# Cloudflare — Workers Static Assets (new project, non-destructive)

This repo has two **different** surfaces:

| Surface | What it is | Cloudflare fit |
|---------|------------|------------------|
| **`static-site/`** | HTML/CSS landing (brochure) | **Workers Static Assets** or Pages — static files only |
| **`streamlit_app.py`** | Interactive Python dashboard | **Not** Cloudflare serverless — needs a long-lived Python host (e.g. Streamlit Community Cloud, free) |

**Honest constraint:** there is **no zero-cost** way to run Streamlit *inside* a Cloudflare Worker. A **browser-only** “interactive” demo would require **real** JSON/CSV committed or generated by CI from the pipeline (`data/exports/` is gitignored by default). Options: (1) ship **sample exports** under `static-site/data/` from `python -m src.analytics` with a clear **“example ONS pull”** label, plus client-side charts (**Chart.js** / **Vega-Lite**); (2) keep Streamlit as the interactive demo and use Cloudflare only for the **landing + links**. This doc assumes **(2)** unless you add checked-in exports and small JS.

**Do not** delete routes, Workers, or DNS without an explicit owner-approved list. Use a **new** Worker name.

## Deploy (CLI)

1. Install [Wrangler](https://developers.cloudflare.com/workers/wrangler/install-and-update/) and authenticate on **your** machine (not this agent).
2. (Optional) Refresh **demo** JSON from the Python pipeline — **real ONS-derived exports**, committed for static hosting:
   ```bash
   python -m src.analytics
   python tools/export_demo_assets.py --from-exports
   ```
3. From repo root:
   ```bash
   npx wrangler deploy
   ```
4. Interactive **browser demo**: open **`/demo.html`** on the deployed Worker URL (Chart.js loads from jsDelivr CDN). **`index.html`** is the hub; link between them.
5. If you use Streamlit Community Cloud, point visitors to your deployed Streamlit URL from the hub or README (the Worker does **not** run Python).

Configuration: root `wrangler.toml` + `workers/static-landing.js` — assets directory **`static-site`**. See Cloudflare [Static Assets](https://developers.cloudflare.com/workers/static-assets/).

## Pages vs Workers + Assets

**Workers Static Assets** (this layout) co-deploys asset hosting with optional Worker logic — good when you may add headers, redirects, or HTMLRewriter later. **Pages** is also valid for static-only; use whichever matches your account defaults. Neither runs Python/Streamlit.
