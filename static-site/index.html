Thomas Gollogly — project demos

Pulls official ONS CSVs (inflation & public borrowing), validates structure, caches Parquet, runs analytics in DuckDB (rolling averages, YoY inflation, monthly PSNB totals), and visualises results in Streamlit or a static Chart.js snapshot — with pytest and CI on GitHub. For sources, limitations, and reproducible commands, see the repo case studies (evidence-led; no employment outcome claims).

Interactive Streamlit dashboard

Plotly charts, downloadable CSV exports, rolling windows, and a plain-language read of the latest pull. Data refreshes when you run a fresh pipeline pull from ONS URLs in the repo config.

  • Run locally: streamlit run streamlit_app.py
  • Host (free): Streamlit Community Cloud
  • Requires network access to ONS for a fresh pull

Pipeline Engineering

Parquet cache, DuckDB SQL views, exports (CSV/JSON/Parquet), tests and CI — README architecture diagram.
