Portfolio · reproducible macro pipeline

UK Macro Analytics Engine

Pulls official ONS CSVs (inflation & public borrowing), validates structure, caches Parquet, runs analytics in DuckDB, and visualises results in a Streamlit dashboard — with pytest and CI on GitHub.

Open interactive demo (browser charts) Streamlit Community Cloud View on GitHub

Interactive on Cloudflare: deploy static-site/ with Workers Static Assets — open /demo.html for Chart.js dashboards fed by committed pipeline exports (see docs/CLOUDFLARE_STATIC.md). Streamlit is optional and needs Community Cloud or local Python.

Interactive Browser demo

CPIH YoY and PSNB £m from committed static-site/demo/*.json (built from the same DuckDB analytics as the Python export step). Chart.js, sliders, downloads — no server-side compute on Cloudflare.

Pipeline Engineering

Requests with retries, schema checks, Parquet cache under data/cache/, DuckDB views, and analytics SQL — documented in the README architecture diagram.

  • Lint: ruff check
