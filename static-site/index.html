UK Macro Analytics Engine

Pulls official ONS CSVs (inflation & public borrowing), validates structure, caches Parquet, runs analytics in DuckDB, and visualises results in a Streamlit dashboard — with pytest and CI on GitHub.

Open Streamlit Community Cloud View on GitHub README · run locally

After you deploy streamlit_app.py on Community Cloud, edit this file and point the primary button at your public app URL so visitors land on your dashboard in one click (static-site/index.html → hero → first href). Until then, Cloud opens the hoster login / app picker.

Interactive Dashboard

Plotly charts, downloadable CSV exports, rolling windows, and a plain-language read of the latest pull. Data refreshes when you request it from ONS URLs in the repo config.

  • Run locally: streamlit run streamlit_app.py
  • Requires network access to ONS for a fresh pull

Pipeline Engineering

Requests with retries, schema checks, Parquet cache under data/cache/, DuckDB views, and analytics SQL — documented in the README architecture diagram.

  • Tests: pytest -q
  • Lint: ruff check
