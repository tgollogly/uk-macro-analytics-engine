Privacy & AI notice

Portfolio front-end files are mirrored here for a static demo hub. This page describes behaviour on this host; the canonical personal site may differ.

Static mirror. You may be viewing these HTML/CSS/JS files from the uk-macro-analytics-engine repo (e.g. Workers Static Assets). It is not the same deployment as tgollogly.dev. Loading pages still involves network requests your browser makes to CDNs, APIs, and third-party hosts listed below.

Cookies and identifiers

This mirrored static bundle does not ship first-party analytics or advertising scripts. We do not assert that no cookies or storage ever occur: third-party requests (fonts, map tiles, chart libraries, weather APIs, or an AI backend if you use ATS) may set or use identifiers under those parties’ policies. This page has not been independently audited.

Optional chat (disabled on this mirror)

The portfolio’s optional chat widget is not loaded on this hub (chat-disabled.js). Chat-related claims in upstream portfolio copy do not apply here.

What each mirrored demo does

  • Beneish M-Score Screener — runs in your browser; figures you enter are not sent to our backend in the shipped script paths.
  • BundleBuilder — case details stay in the page until you close the tab.
  • Heat Anomaly Detector and Thermal Compare — request weather and map data from third parties (e.g. Open-Meteo, OpenStreetMap raster tiles per the OSM tile policy, RainViewer radar). Those services receive normal HTTP requests (including IP as usual for web requests).
  • ATS Resume Matcher — when you click Analyse match, Generate cover letter, or Improved CV, the page POSTs JSON (mode, cv, jd) to the URL in config.js (the public uk-macro-ats-gate Worker at https://uk-macro-ats-gate.thomasgolloglypagesdev.workers.dev/api). The gate checks your browser’s origin, enforces server-side usage caps (aggregated counters only; no CV storage for quota), and forwards to a private Worker that holds the API key and calls Google Gemini. Connectivity and responses from this mirror have not been verified in every environment; do not paste sensitive text.

UK Macro interactive charts (../demo.html)

That page loads Chart.js from jsDelivr and plots committed pipeline export JSON (ONS-derived statistics). It is not “invented sample data” — treat figures as non-authoritative snapshots and see the engine README / OGL notice.

Third-party services (non-exhaustive)

Depending on which pages you open, your browser may contact:

  • Google Fonts — typefaces
  • jsDelivr / other CDNs — JavaScript libraries
  • Open-Meteo, OpenStreetMap (tiles), RainViewer, AWS elevation — weather and maps in the heat demo
  • Cloudflare Workers (gate + private ATS backend on this account) — only when you trigger ATS from this hub
  • Google Gemini — only via that ATS backend when it succeeds
