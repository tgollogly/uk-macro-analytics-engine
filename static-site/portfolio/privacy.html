Privacy & AI notice

Selected front-end demos are mirrored here for a static demo hub. This page describes behaviour on this host; the canonical personal site may differ.

Static site. These pages are served as static HTML/CSS/JS from the uk-macro-analytics-engine project (Workers Static Assets). Opening a demo still triggers network requests to CDNs, weather APIs, or chart libraries as listed below.

Cookies and identifiers

This mirrored static bundle does not ship first-party analytics or advertising scripts. We do not assert that no cookies or storage ever occur: third-party requests (fonts, map tiles, chart libraries, weather APIs) may set or use identifiers under those parties’ policies. This page has not been independently audited.

Optional chat (disabled on this mirror)

The upstream optional chat widget is not loaded on this hub (chat-disabled.js). Chat-related claims in older upstream copy do not apply here.

What each mirrored demo does

  • Beneish M-Score Screener — runs in your browser; figures you enter are not sent to our backend in the shipped script paths.
  • BundleBuilder — case details stay in the page until you close the tab.
  • Heat Anomaly Detector and Thermal Compare — request weather and map data from third parties (e.g. Open-Meteo, OpenStreetMap raster tiles per the OSM tile policy, RainViewer radar). Those services receive normal HTTP requests (including IP as usual for web requests).
  • Macro trend explorer and Pipeline coverage explorer — load committed static-site/demo/*.json and manifest.json in your browser only (no live ONS pull on this host).
  • ATS Resume Matcher — retired on this hub. The page at ats-matcher.html is informational only; it does not POST CV or job text. Optional gate/backend Workers in the repo (docs/ATS_API_WORKER.md) are for developer review only and are not linked from the public demo hub.

UK Macro interactive charts (../demo.html)

That page loads Chart.js from jsDelivr and plots committed pipeline export JSON (ONS-derived statistics). It is not “invented sample data” — treat figures as non-authoritative snapshots and see the engine README / OGL notice.

Third-party services (non-exhaustive)

Depending on which pages you open, your browser may contact:

  • Google Fonts — typefaces
  • jsDelivr / other CDNs — JavaScript libraries
  • Open-Meteo, OpenStreetMap (tiles), RainViewer, AWS elevation — weather and maps in the heat demo

Historical AI stack (not active on this hub)

Earlier builds could POST to a Cloudflare gate Worker for Gemini-backed ATS. That flow is disabled on the public demo hub; see docs/ATS_API_WORKER.md for optional worker code retained in the repo only.
